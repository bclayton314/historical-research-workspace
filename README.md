# Historical Research and Video-Essay Workspace

A full-stack application for organizing historical research,
sources, notes, timelines, claims, citations, episode outlines,
and video-essay scripts.

## Technology

- React
- TypeScript
- Vite
- Python
- Flask
- SQLAlchemy
- SQLite

## Stage 1 features

- Create research projects
- List existing projects
- Track project status
- Store a central research question
- Flask REST API
- React dashboard
- Backend validation
- Backend tests

## Run the backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
